# Egypt Tourism Image Prompt Pack

Use these prompts in your preferred image model (Midjourney, SDXL, Leonardo, Flux).

## Global Generation Settings

- Style: ultra-realistic travel photography
- Quality target: 4K
- Lighting: natural (golden hour / sunset where specified)
- No text, no logos, no watermarks
- Camera look: full-frame DSLR or mirrorless, natural color grading, high dynamic range

### Global Negative Prompt

cartoon, illustration, painting, anime, 3d render, cgi, lowres, blurry, noisy, overprocessed, plastic skin, fake textures, watermark, logo, text, caption, frame, posterized, surreal distortion

## 7) Consistency Workflow (Recommended)

1. Generate 4-8 candidates per prompt.
2. Keep one visual direction per content section (hero / civilizations / regions / attractions).
3. Re-run selected winners with same seed and slight prompt tweaks for consistency.
4. Export at high resolution then web-optimize (WebP/AVIF) for frontend performance.
